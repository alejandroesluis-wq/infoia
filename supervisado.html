¿Qué es el aprendizaje supervisado?

El aprendizaje supervisado es una rama del aprendizaje automático en la que una computadora aprende utilizando datos etiquetados. Esto significa que los datos contienen ejemplos con sus respuestas correctas.

El sistema analiza esos ejemplos para aprender patrones. Después, puede utilizar lo aprendido para realizar predicciones sobre datos nuevos.

Características principales

  • Utiliza datos etiquetados para aprender.
  • Aprende patrones a partir de ejemplos.
  • Permite realizar predicciones sobre datos nuevos.
  • Se utiliza para clasificar información y predecir valores.

Clasificación y regresión

Clasificación

La clasificación consiste en asignar datos a categorías. Por ejemplo, un sistema puede clasificar un correo electrónico como spam o como correo normal.

Regresión

La regresión permite predecir valores numéricos. Por ejemplo, un sistema puede estimar el precio de una vivienda según su tamaño y ubicación.

Ejemplos de aplicación

1. Detección de spam

Aprende a distinguir entre correos electrónicos no deseados y correos normales a partir de ejemplos previamente clasificados.

2. Predicción de precios

Utiliza datos de viviendas, como el tamaño, la ubicación y los precios anteriores, para estimar cuánto podría costar una vivienda.

3. Diagnóstico médico asistido

Analiza datos médicos previamente etiquetados para ayudar a identificar patrones relacionados con determinadas enfermedades. Sus resultados deben ser evaluados por profesionales de la salud.
